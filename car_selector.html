Car Selector Web App

This project is a web app I made for my IDM 231 class, Scripting for Interactive Digital Media. The premise of the web app is that the user can either click on a car, or select a date, and the display will update to show information about the car, and a sound will play. The dates on the input coorelate to zodiac signs. This was used as an introduction to JavaScript, and it taught me the fundamentials of JavaScript, how to write functions, and how to use JS to further develop websites beyond HTML and CSS.
